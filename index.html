Installing content onto Xbox 360 (ABadAvatar)

Before you copy anything: use files you own or are authorized to use; make a backup first; confirm your console/dashboard supports the format. Paths below are common examples, not universal defaults. Set the content paths in ABadAvatar to match the drive and folder layout actually used by your console.

Games — extracted files, ISO, GOD, and multi-disc releases
  1. Identify the format. An .iso is a disc image; extracted game files often contain default.xex; GOD (Games on Demand) output is a numbered package folder. ABadAvatar must support the format you choose.
  2. For an extracted game: copy the complete extracted game folder into your configured games path (often a folder such as Hdd1:/Games/Game Name/). Keep default.xex and its neighboring files together; avoid accidental double nesting such as Games/Game/Game/default.xex.
  3. For an ISO you want as GOD: use ISO2GOD information and downloads (ConsoleMods). Select the ISO, choose an output folder, convert it, then copy the produced GOD content folder to Hdd1:/Content/0000000000000000/ while preserving the generated title-ID and package structure. Rescan the dashboard.
  4. Disc 1 install disc + Disc 2 play disc: check the release notes or a trusted compatibility list to determine what each disc contains. If Disc 1 is only an install/data disc and Disc 2 is the play disc, extract the install disc with a suitable ISO extraction tool such as extract-xiso or ISO2GOD / ConsoleMods guidance. Inspect the extracted files and identify the game data/content by title ID. Convert the play disc to GOD if that is your chosen format, then merge/copy only the required install-data files into the matching title's expected structure. Do not blindly overwrite files or combine unrelated title IDs. Some games expect data under Content/0000000000000000/TITLEID/00000002/; others use a game-specific folder or a different disc workflow. Verify the exact title-specific method first.
  5. DiscXplorer: useful for inspecting Xbox 360 disc/content layouts and finding files on install discs. Use it to inspect/extract your own disc image and identify the correct game-data folder; preserve paths and title IDs. Search for a trusted source/community reference before downloading: ConsoleMods Xbox 360 documentation.
  6. After copying: refresh/rescan the configured ABadAvatar path, confirm the title appears, and test it. Multi-disc games may need a dashboard-specific disc-swap or launch setup.

Common paths: extracted games: Hdd1:/Games/ (if configured); GOD games: Hdd1:/Content/0000000000000000/TITLEID/00007000/ is a common GOD container location; supplemental content may use 00000002. Keep the package's own generated directory structure intact and follow the format expected by your dashboard.

DLC — title IDs, content IDs, and refresh
  1. Match DLC to the exact base game and title ID. Regional or edition differences can mean a DLC package is not recognized by another version.
  2. For many Xbox 360 DLC packages, the common content path is Hdd1:/Content/0000000000000000/TITLEID/00000002/. Replace TITLEID with the game's title ID (often eight hexadecimal characters). The inner package filename/content ID is normally significant—do not rename it arbitrarily.
  3. Copy the full package into that folder while preserving the folder structure. If the download is an archive, extract it first only when it contains a package file or a documented content tree.
  4. Refresh the dashboard's content list and launch the base game. Check in-game menus for the add-on. Some DLC requires an appropriate license/entitlement and may not work merely because the files are present.
  5. If it does not appear, verify title ID, region/edition, file integrity, content path, and whether the package is actually DLC rather than a title update or theme.

Typical structure: Content/0000000000000000/4D5307E6/00000002/<content package> (example title ID only). Never assume the example ID belongs to your game.

Arcade — make a package usable on Xbox 360
  1. Identify whether the item is an XBLA/GOD package, an extracted game, or an ISO. These are not interchangeable formats. Check that the title ID and package are for the intended game.
  2. For a GOD/XBLA package: preserve the generated content folder and copy it under Hdd1:/Content/0000000000000000/, keeping the title-ID and package directories intact. Rescan the dashboard.
  3. For an extracted game: put the complete extracted folder in the configured games path (for example Hdd1:/Games/Arcade Title/) only if the dashboard supports launching that format.
  4. Package unlock / compatibility: on a compatible modified console, GOD Unlocker (GitHub) can unlock supported GOD packages for launch on JTAG/RGH consoles. Make a backup first; use it only with content you are authorized to use. It does not convert an ISO to GOD or guarantee every package will work.
  5. XM360: a homebrew utility commonly used to scan content and manage/unlock DLC/XBLA packages on compatible modified consoles. Use a reputable community source and read its documentation before running it; it may not be compatible with every dashboard or package. Do not use it to bypass licensing for content you do not own.
  6. Afterward, refresh/rescan content, confirm the title is listed, and test launch. If it is missing, re-check the content path, title ID, package integrity, console/dashboard compatibility, and whether the item needs a license or a different format.

References: GOD Unlocker source and notes · ConsoleMods Xbox 360 wiki. A current authoritative XM360 project link could not be confidently verified, so use a trusted community archive rather than an arbitrary mirror.
